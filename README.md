# 黔海｜产业出海社媒数字员工

> **AI × 广电｜#Guikesong｜交互原型**  
> 让数字员工持续经营海外社媒，并把客户结果追溯到内容。

## 项目是什么

企业只需给出产品、目标国家、客户类型、预算和红线，黔海围绕同一个经营目标，连续组织海外社媒内容、传播运营、客户信号识别和低风险承接。

它不是“AI 写一篇稿、剪一条视频就结束”，而是把内容之后的传播、互动、客户接管和结果回传连成一条链路。

```text
品牌事实与经营目标
  → 多语种社媒内容
  → 审核、排期与跨平台传播
  → 评论／私信／邮件／表单信号
  → 海外客户识别与低风险承接
  → 触碰商务红线后停止并交给人
  → 内容、客户、行动与结果可追溯
```

标准、低风险的社媒动作目标为无人值守运行；**价格、折扣、合同、交期、独家代理以及异常事项必须由人决定**。

## 为什么选择海外社媒

项目要验证的业务假设是：部分产业企业做出口时依赖展会、平台和原有渠道，却没有持续经营海外社媒；即使开始做，也常停在通用模剪、发布和曝光数据，内容没有围绕采购角色、业务证据和下一步行动持续运营。

这仍是 **100 天 PoC 待验证假设**。当前没有真实企业访谈、账号数据或客户结果支撑，不能写成已证明的行业结论。

## 为什么属于 AI × 广电

广电的作用不是在名称里“站台”，而是成为国际内容与传播运营方：提供策划、拍摄制作、内容审核、传播渠道和账号运营能力。产业企业提供经营目标、真实资料和业务接管人；黔海负责让数字员工在授权范围内连续行动、识别客户信号并回传结果。

相对“AI 写稿＋一键发布”，黔海增加了四件事：

1. 内容绑定目标国家、采购角色和品牌事实；
2. 发布后继续汇聚评论、私信、邮件和表单信号；
3. 低风险动作自动推进，高风险动作停下并携带上下文交给人；
4. 客户可追溯到原始内容、传播触点和后续行动。

## 三位数字员工

| 数字员工 | 在授权范围内做什么 | 什么时候停下 |
|---|---|---|
| 国际内容数字员工 | 组织多语种内容、审核排期和渠道版本 | 缺少品牌事实、素材授权或审核结论 |
| 客户信号数字员工 | 汇聚互动，补全公司与采购角色，判断需求和优先级 | 身份或意图置信度不足 |
| 客户承接数字员工 | 回复已批准的常见问题、发送已批准资料、记录下一步 | 涉及价格、合同、交期、折扣或独家代理 |

AI 数字人、AI 带播和 AI 直播属于计划接入的内容形态，**不是本仓库当前已经完成的生产模块**。

## 评委现场只看这一条故事

**贵州抹茶 × 马来西亚食品原料进口商｜模拟演示**

```text
1. 增长控制塔
   看到“贵州抹茶进入马来西亚”的唯一经营目标
        ↓
2. 经营任务设置
   确认客户类型、预算、允许动作、禁止事项和人工接管人
        ↓
3. 数字员工运行台
   查看 AI 为什么安排内容、何时执行、使用了什么权限
        ↓
4. 内容与流量运营
   模拟生成并排期面向食品原料进口商的英文社媒内容
        ↓
5. 客户经营
   模拟识别渠道商询问；普通资料自动发送，独家代理触发红线停止
        ↓
6. 收入归因
   追溯 CONTENT-001 → TOUCH-001 → LEAD-001 → HANDOFF-001
```

现场只证明三件事：标准社媒动作能连续执行并留下记录；商务红线能阻止 AI 越权承诺；客户信号能追溯到原始内容和传播触点。

## 100 天 PoC

只接入一个真实项目：1 个品牌／产品、1 个目标国家、1 类海外客户、1 条社媒内容到客户接管链路。

只验证四项指标：

1. 合格客户信号数量；
2. 首次响应时间；
3. 人工接管信息完整率；
4. 客户来源可追溯率。

在取得真实客户、账号、负责人和数据之前，不设置收入承诺。

## 明确不做

- 不在现场同时展开多个行业；
- 不做 DTC 商城、支付、物流和完整订单履约；
- 不做复杂平台后台、插件市场或重型视频模型管理；
- 不让 AI 承诺价格、合同、交期、折扣或独家代理；
- 不把模拟客户、模拟询盘和模拟收入写成真实结果。
