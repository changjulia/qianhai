# 黔海OS｜平台一页纸介绍

## 使用方法

1. 解压代码包。
2. 双击 `index.html`，使用 Chrome、Edge 或 Safari 打开。
3. 页面中的主要文字支持直接点击编辑。

## 文件说明

- `index.html`：页面内容与结构。
- `styles.css`：页面样式与 A4 横版打印设置。
- `assets/platform-homepage.png`：平台首页展示图。
- `assets/contact-qr.png`：合作联系二维码。

## 导出 PDF

浏览器打开页面后选择“打印”，纸张设置为 A4、方向选择横向、边距选择无，并开启背景图形，然后保存为 PDF。

请保持 `index.html`、`styles.css` 和 `assets` 文件夹的相对位置不变。
