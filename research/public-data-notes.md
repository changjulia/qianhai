## 2. 建议在 Demo 中形成的洞察（明确标为“AI 推演”）

以下不是官方原文结论，入库时 `truth_type` 应为 `inference`：

1. **优先地域**：依据 DOSM 的机构数量，首轮账户发现可优先 Selangor、Kuala Lumpur、Johor；这是对 F&B 机构集中度的业务推演，不代表抹茶采购量排名。
2. **优先客群**：食品原料进口商、饮料/咖啡连锁、烘焙食品制造商；官方数据只证明 F&B 服务生态规模，具体抹茶买家需由公开企业目录或 Mock 账户补足。
3. **核心证据内容**：产能、批次稳定、检测、应用适配、样品政策比泛产地宣传更接近 B2B 采购决策；属于产品策略推演。
4. **Halal 处理**：把“是否可作 Halal 宣称/认证机构是否仍获 JAKIM 认可”设为强制人工核验项。不能仅凭企业自述自动回复“已认证”。
5. **法规处理**：样品、正式商用进口、零售包装可能对应不同文件与标签要求；Demo 可展示检查清单，但不得输出“已保证准入”。

## 3. 可安全制作的 Mock 数据边界

公开数据不足以支持以下企业级字段，建议全部 Mock，并在 UI 标记“Demo 模拟”：

- 虚构茶企的工厂面积、产能、员工数、SKU、MOQ、报价、交期、样品政策、认证状态；
- 马来西亚客户名称、联系人、WhatsApp、邮箱、采购量、预算、商机金额；
- 内容曝光、点击、询盘、广告成本、归因收入；
- 报价单、检测报告、证书、合同和经销权限。

Mock 数值应符合三个约束：企业产能不得冒用产业总量；认证不得默认“已具备”；最终报价、账期、独家代理、交期承诺必须进入人工审批。

## 6. 数据口径冲突与使用注意

- 个别铜仁官方报道对同一年度“产值”使用了不同口径（如产业综合产值与产品产值）。Demo 主指标统一采用贵州省农业农村厅披露的 **2024 年综合产值 10.02 亿元**，并保留“综合”字样，不混用其他口径。
- “全球第二”“全球最大”等表述应显示为“据官方公开资料”，且只用于产业/设施描述，不能映射到虚构企业。
- DOSM 经济普查数据参考年为 2022，发布日期为 2024；页面必须同时呈现数据期，不能显示成“2024 年机构数”。
- MATRADE 的 RM1.371 trillion 是马来西亚全部进口总额，只能作宏观背景，不得表达为食品、茶或抹茶进口额。
- JAKIM 认可境外认证机构名单会变化；现场 Demo 可展示“需实时核验”状态，不要把历史名单硬编码为长期有效。
