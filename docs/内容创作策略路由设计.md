# 黔海内容创作策略路由设计

> 状态：贵客松原型开发基线  
> 版本：2026-08-29  
> 适用范围：内容流量页、内容生产 Agent、任务编排与行动审计

## 1. 目标

将当前“所有内容任务进入同一条固定流水线”升级为“AI 先判断最合适的创作方法，再调用对应工作流执行”。

用户下达经营目标时，不需要先理解工具和工作流。系统根据产品资料、真实素材、参考内容、目标买家、平台与风险边界选择路径，并说明选择理由、缺失输入和后续步骤。

## 2. 三类一级创作策略

| 策略 ID | 前台名称 | 适用条件 | 核心约束 |
|---|---|---|---|
| `viral_remix` | 爆款结构迁移 | 存在与目标买家、平台和内容目标匹配的高表现参考 | 迁移钩子、证明顺序和节奏；不复制竞品品牌、产品事实、原文案和素材 |
| `product_led` | 从产品生成 | 产品事实较完整，但缺少成熟创意或可直接剪辑素材 | 从目标买家问题和可验证产品事实生成主题、脚本与分镜；不补全未提供的商业事实 |
| `asset_led` | 基于素材创作 | 已有足够的工厂、产品、案例、检测或应用场景素材 | 先识别素材中真实可见的证明，再组织内容；画面不支持的事实不得写入脚本 |

“爆款复刻”在产品界面统一表述为“爆款结构迁移”或“参考爆款创作”，强调可迁移的是方法结构，不是竞品内容本身。

## 3. AI 路由决策

### 3.1 决策输入

- 经营目标：市场、目标买家、转化目标、平台、语言、时间与预算。
- 产品证据：产品名称、规格、包装、认证、产能、交付和已确认卖点。
- 素材证据：素材类型、可见对象、时长、画质、授权、可用平台和可支持事实。
- 参考证据：平台表现、买家匹配度、钩子、结构、节奏、逐镜分析完整度和版权风险。
- 执行边界：事实红线、品牌规范、合规规则、自主等级与审批规则。

### 3.2 默认决策顺序

1. 如果存在高匹配参考，且逐镜分析和产品映射均完整，推荐 `viral_remix`。
2. 否则，如果真实素材能支持至少一条完整的“钩子—证明—价值—CTA”结构，推荐 `asset_led`。
3. 否则，如果产品和买家信息完整，推荐 `product_led`。
4. 如果三条路径都缺少关键输入，不生成具体内容，先创建“补充资料”或“人工确认”任务。

AI 必须返回：推荐路径、置信度、理由、已使用证据、缺失输入、候选路径及其取舍。

## 4. 路径工作流

```text
viral_remix
参考发现 → 精确拆解 → 产品映射 → 本地素材回填 → 分镜重构 → 差异/泄漏检查 → 审核

product_led
买家问题 → 内容主题 → 事实脚本 → 分镜 → 素材缺口 → 生成/匹配画面 → 事实检查 → 审核

asset_led
素材理解 → 可用证明识别 → 结构规划 → 剪辑脚本 → 缺口补齐 → 合成 → 素材落地检查 → 审核
```

顶层任务看板继续使用统一的经营进度；路径差异在任务详情和 Agent 工作现场展开，避免将内容运营拆成三个孤立产品。

## 5. 交互要求

- “新建任务”默认由 AI 推荐路径，用户可以在启动前改选。
- 任务卡显示策略标签，但不用标签取代业务任务标题。
- 任务详情显示 AI 推荐理由、置信度、必要输入、当前路径和路径变更记录。
- 路径切换只影响尚未执行的步骤；已生成产出保留为历史版本，不得静默覆盖。
- 筛选项增加“创作策略”，支持查看 AI 推荐与人工改选的任务。
- 发布前的事实、品牌、合规与商务承诺审核不因创作路径而取消。

## 6. 数据模型

```ts
type CreationStrategy = 'viral_remix' | 'product_led' | 'asset_led';

type StrategyDecision = {
  strategy: CreationStrategy;
  source: 'ai_recommended' | 'user_selected';
  confidence: number;
  reason: string;
  evidenceIds: string[];
  requiredInputs: string[];
  missingInputs: string[];
  workflowTemplate: string;
  decidedAt: string;
  decidedBy: string;
};
```

任务还应保留 `strategy_history`，记录原路径、新路径、切换人、原因、已保留产出和新工作流起点。

## 7. 质量与安全规则

- `viral_remix`：必须有完整参考分析；检查竞品品牌、文案、产品事实和行业信息泄漏。
- `product_led`：所有数字、规格、认证、产能、MOQ、交付和功效必须来自已确认产品资料。
- `asset_led`：脚本的动作、对象和时长必须能被真实素材支持；素材授权不完整时阻断发布。
- 所有路径共用事实核验、品牌规范、平台合规和人工审核能力。

## 8. 分阶段交付

### P0：原型可见

- 任务数据增加创作策略、来源、理由和置信度。
- 内容看板增加策略标签和策略筛选。
- 任务详情增加 AI 策略决策卡及手动切换。
- 新建任务模拟 AI 推荐一条路径。

### P1：真实路由

- 建立策略决策服务和可配置决策规则。
- 为三条路径建立独立的工作流模板、输入契约和质检契约。
- 将决策依据、路径变更与生成产出写入行动账本。

### P2：闭环优化

- 把内容表现、询盘质量与路径选择关联，形成项目级策略记忆。
- 在不改变事实和权限边界的前提下，允许 Agent 根据结果调整后续任务的推荐路径。

## 9. P0 验收标准

1. 每张内容任务卡可识别当前创作策略。
2. 用户能按三类策略筛选任务。
3. 任务详情显示“AI 推荐/人工选择”、推荐理由和置信度。
4. 用户切换路径后，任务卡、详情和工作现场的路径同步更新。
5. 新建任务默认展示 AI 推荐路径及其理由。
6. 现有任务推进、审核、恢复执行和进入排期的交互不回归。
